# BOILER ROOM Batumi — Telegram-бот

Бот для брони столов на трансляции. Гость выбирает матч или бой, число гостей, оставляет имя и телефон. Администратор получает заявку с кнопками «Подтвердить» и «Отклонить». За час до начала гость получает напоминание.

## Что умеет

- **Гость:** афиша с фото, бронь стола в 4 шага, статус заявки, напоминание за час, меню акций, адрес и часы.
- **Админ** (кнопка «⚙️ Админ-панель» или `/admin`):
  - добавить трансляцию **одним сообщением**: «Барселона — Реал, 01.11 21:00» или «UFC завтра 23:00», афишу можно приложить к этому же сообщению. Админ может просто написать это боту, без кнопок;
  - добавить акцию (текст, фото, день недели или дата окончания);
  - подтверждать и отклонять заявки;
  - анонсировать трансляцию или акцию всем гостям одной кнопкой;
  - разовая рассылка всем гостям;
  - удалять трансляции и акции.
- **Автоматика:** прошедшие трансляции пропадают сами; акция «по средам» напоминает гостям каждую среду с 12:00 (по Батуми).

Всё работает на бесплатных сервисах: GitHub (код и напоминания по расписанию), Vercel Hobby (сервер), Upstash Redis (база, бесплатный тариф).

## Структура

```
api/telegram.js      вебхук Telegram (Vercel Function)
api/cron.js          напоминания (вызывает GitHub Actions)
lib/bot.js           сценарии гостя, админки, напоминаний
lib/store.js         хранилище (Upstash REST или память)
lib/telegram.js      обёртка над Telegram Bot API без зависимостей
lib/time.js          даты и часовой пояс Батуми (UTC+4)
lib/config.js        название, адрес, часы — заполнить перед запуском
scripts/             настройка вебхука, демо-данные, генерация картинок
public/              лендинг и картинки бота
test/                автотесты сценариев (npm test)
```

## Запуск за 6 шагов

### 1. Бот в Telegram
В @BotFather: `/newbot`, имя и username. Сохраните токен — это `TELEGRAM_BOT_TOKEN`.

### 2. База (бесплатно)
Зарегистрируйтесь в Upstash, создайте Redis-базу (Free). Скопируйте `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.

### 3. Код на GitHub
```bash
git init && git add . && git commit -m "BOILER ROOM bot"
gh repo create boiler-room-bot --private --source . --push
```

### 4. Деплой на Vercel
Vercel → Add New → Project → импорт репозитория (Framework: Other, сборка не нужна). Добавьте переменные окружения:

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из BotFather |
| `WEBHOOK_SECRET` | любая длинная случайная строка |
| `ADMIN_CHAT_IDS` | Telegram ID админа (через запятую, если несколько). Узнать: бот @userinfobot |
| `CRON_SECRET` | любая длинная случайная строка |
| `UPSTASH_REDIS_REST_URL` | из шага 2 |
| `UPSTASH_REDIS_REST_TOKEN` | из шага 2 |
| `PUBLIC_URL` | адрес проекта, например `https://boiler-room-bot.vercel.app` |

Деплойте, затем проверьте: открывается страница с текстом «BOILER ROOM bot is alive».

### 5. Вебхук
Локально (Node 18+):
```bash
TELEGRAM_BOT_TOKEN=... WEBHOOK_SECRET=... PUBLIC_URL=https://... node scripts/setup-webhook.mjs
```

### 6. Напоминания
GitHub → репозиторий → Settings → Secrets and variables → Actions:
- `APP_URL` — тот же `PUBLIC_URL`;
- `CRON_SECRET` — тот же, что в Vercel.

Workflow `reminders` запускается каждые 10 минут. Можно проверить вручную: Actions → reminders → Run workflow.

## Перед показом гостям

1. Заполнить `lib/config.js`: адрес, часы, телефон (сейчас стоят `TODO`).
2. Указать username бота в `public/index.html` (`BOT_USERNAME`).
3. Добавить реальные трансляции через админ-панель (или демо: `npm run seed` с переменными Upstash).
4. Картинки: `python3 scripts/make-images.py` перерисует фон. Свои афиши можно прислать боту фото — Telegram сам сохранит их.

## QR-код на столы

Ссылка для QR: `https://t.me/<username_бота>?start=table`. Сгенерировать можно любым бесплатным генератором QR. Для гостя это одно касание: открыл — сразу меню.

## Ограничения

- Бот может писать только тем, кто уже нажал «Старт» или бронировал. Это ограничение Telegram.
- Напоминания работают с точностью до 10 минут (частота GitHub Actions).
- Хранилище в Upstash Free: до 10 000 команд в день — для одного заведения с запасом.
- Без `UPSTASH_*` бот работает в памяти и сбрасывает данные при перезапуске. Для демо на локальной машине это нормально.
